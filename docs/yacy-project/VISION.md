## 1. Головна мета проекту
Створення потужного пошщукового інструмента який буде краще ніж гугл чи яндекс свою френдлі юзерс системою та функціоналом, я ненавиджу корпоративні рішення та докладаю зусиль для того щоб створити відкритті рішення кращіми ніж всі інші. Для мене важливо чистий код можливість підтримки, покращення продуктивності реально легкий та сучасний дизайн та саме головне це функціональність. На сьогоднішній день ми маємо пошуковий із 90х який повністю слабкий, не підтримує ітерації пошуку не шукає довгі запити сканує сайти тільки для того щоб знаходити інформацію по тегах це жахливо.

## 3. Нові функції які хочу додати
<!-- Що має бути в проекті чого зараз немає? -->

- Створити новий повноцінний шаблон для юзабіліті гарний пошуковий інструмент це вже частина успіху треба створити світлу тему з гарними акцентами з гарними кнопками не з 90х років. Верзня панель додати кнопки входу, додати праворуч кнопку меню де буде відкриватись баттомшит з рекомендваними ресурсами у вигляді грід іконка та назва при натисканні відкрриваєтться ресурс в новій вкладці, як я вже казав щоб можна було додавати ці ресурси через алмін панель.
- Запропонуй відкритий варіант для автифікації користувачів які бажають отримувати від нас сповіщення та будуть раді користуватись додатковими інструментами які ми будемо додавати до адмінки.
- Створити кабінет для користувачів наразі в них буде тільки можливість додавати запит на індексування їх сайтів наш робот буде перевіряти ці сайти на користь та додавати їх в пошукові запити якщо це не спам сайти та не сайти порно чи казіно. 
- AI-механізм незадоволених запитів → автоіндексування роззроби концепцію швидкого та максимально ефективного пошуку можна на базі штучного інтелекту
- Рощзробити механіку як ми будемо ділитись індексами з мережою але ділимось тільки тими індексами які не є брудом пропагандорю лгбт пропагандоб порно та пропаганда корпоративних рішень все інше наздоровʼя 
- Адмінка: додати ресурс + іконка → зʼявляється в меню сервісів про це сказав вище 
- Семантичне ранжування (вектори замість рефлінків) - Осье це ідеально запропонуй архітектуру максимально щоб було швидко та якісно можливо навіть з лейер рішенням щоб була база швидкого індексу для робота потім база з детальним індексом
- Розробити механіку якісно го пошуку по всьому інтернету за вказаними параметрами, додати вікно для адміну де він зможе спілдкуватись з роботом для того щоб додавати йому завдання на пошук нових індексів наприкд просто заходжу і кажу нам не вистачає ось таких то данни (Кулінарія, навчання, ітд) він стивить це в чергу для індексу та виконує тоді коли серврер не завантажений та має найнижчий показник відвідуввання

## 5. Технічні рішення
<!-- Що використовувати: мова, фреймворк, БД, API? -->

- Backend: Java (YaCy) + Python (AI сервіси) на мою осмобисту думку джава трохи застарів особливо в тому сенсі як він був написаний в 90х на цьому проекті якщо джава прекрасно працює і ти впевенний що його легко підтримувати то залишаємо якщо ні то пропнуй кращі рішення хоч на c++ пайтон бомба чудово працює якщо класно написаний. 
- Embeddings: HuggingFace multilingual-e5-base (локально) стосовно векторів для розробки то використовуємо локально якщо це стосується як саме травимо індекси та інше то ні краще розгорнути окремий корнйнер на нашому срвері та створити повну арзітектуру там це має бути і бд і якісний автифікатор для користувачів але з рішенням опенсорс таких багато обирай той що найбільше підтримується та якісно осблуговується для бд постгрес поки лідер кращо нічого ще не бачив, для векторів він також прекрачсно працює 
- Vector DB: PostgreSQL + pgvector (локально) = відповів вище 
- Search index: Solr (вбудований в YaCy) = я реально до кінця не розумію як він працює якщо він підходить для наших завдань то використовуємо якщо ні то створюємо власне рішення шваидке потужне проте я б хотів щоб ми ділились індексами із загальною мережею, але якщо то вже вчорашній день то створюємо власне рішення до якого зможуть підключитись інші та запровадити додаткові зусилля в децентралізації та кожен вузол знімає навантаження з інших такий собі блокченй данних швидкий та потужний оанцюг моджна навіть придумати якусь криптовинагороду за підтримку мережі та штрафи для тих хто її ламає якось так але це просто думка якщо вфігн то нафіг.
