🧠 Семантика, не PageRank

Запит → мультимовний embedding → cosine similarity по індексу. Багатство беклінків більше не дає сайту переваги. SEO-спам втрачає свій основний інструмент.

🚫 Без трекерів

Жодного Google Analytics, шрифтів з CDN, рекламних пікселів. Tailwind, шрифти, іконки — все локально. Cloudflare-проксі вимкнено для admin pages.

🌐 Самостійне розгортання

Один docker compose up -d на твоєму сервері. P2P-протокол YaCy дозволяє ділитися індексом з іншими операторами.

🤖 AI самовідновлення

Запити з нульовими кліками щодня збираються, надсилаються в LLM, який пропонує seed-URL → автоматично краулим. Індекс закриває власні прогалини.

🛡️ Чорний список 400+

Спам, казино, порно, державні пропагандистські медіа, мейнстрім-соцмережі — не індексуються і не пропонуються. Прозорий список у репо.

👤 Кабінет користувача

Авторизація через Authentik (OIDC). Збережені пошуки, закладки, підписки на запити з годинною перевіркою. Без власної бази паролів.

Чому ще одна альтернатива?

Google домінує бо ніхто не може зрівнятися з його crawl-обсягом. Ми не намагаємося. Замість того ми робимо якісно інший пошук:

  • відкритий код, форкається будь-ким за 5 хвилин;
  • без бізнес-моделі реклами — ні в кого нема стимулу запрятувати релевантні результати під SEO;
  • повний контроль над тим що індексується (white/blacklist у файлах, не приховано в API);
  • дані залишаються у тебе — ні embeddings, ні query logs не йдуть до третіх осіб.

Це не заміна Google для всіх. Це другий інструмент — для тих, хто шукає чесний результат і має свою думку про що варто індексувати.

git clone -b feature/remove-third-party-links \
    https://github.com/VladlenVeronov/yacy_search_server.git yacy-fork
cp yacy-fork/deploy/docker-compose.yml ./
cp yacy-fork/deploy/.env.example ./.env
nano .env    # YACY_HOST + POSTGRES_PASSWORD + ADMIN_TOKEN
docker compose up -d
